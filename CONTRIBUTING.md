# CONTRIBUTING

## Branching Strategy

- main - стабільна гілка
- feature/* - нові функції
- fix/* - виправлення помилок
- refactor/* - рефакторинг

## Commit Conventions

Використовуються Conventional Commits:

- feat:
- fix:
- refactor:
- docs:
- test:
- chore:

## Pull Requests

1. Створити окрему гілку.
2. Внести зміни.
3. Створити Pull Request.
4. Пов’язати з Issue.
5. Пройти review.
6. Merge у main.

## Code Review

Перевіряти:

- коректність логіки;
- читабельність коду;
- відповідність конвенціям.

## Resolving Conflicts

1. Оновити main.
2. Виконати merge.
3. Вирішити конфлікти вручну.
4. Закомітити зміни.
