# Library Management System

## Опис проблеми

Бібліотека потребує простого застосунку для обліку книг та їх видачі читачам.

## Цільові користувачі

- Бібліотекар
- Читач
- Адміністратор системи

## Основні сценарії

1. Додати книгу в бібліотеку.
2. Видати книгу читачу.
3. Переглянути список доступних книг.

## Нефункціональні вимоги

- Код має бути тестованим.
- Архітектура повинна легко розширюватися.
- Система повинна обробляти помилки без падіння програми.

## Обмеження Iteration 1

- Немає бази даних.
- Немає GUI.
- Дані зберігаються тільки в пам’яті.
