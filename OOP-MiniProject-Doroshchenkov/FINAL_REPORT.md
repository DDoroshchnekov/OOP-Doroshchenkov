# FINAL REPORT

## Project overview

Library Management System is a console application for managing books and borrowing operations.

## Architecture decisions

The project uses layered architecture:

- Domain
- Application
- Infrastructure
- Console

Dependency Injection is implemented through constructor injection.

## Applied principles

- SOLID
- Encapsulation
- Abstraction
- Repository Pattern

## Testing

Project contains:

- Unit tests
- Integration tests
- Coverage support

## Refactoring

The following improvements were made:

- Removed hidden dependencies
- Simplified repository logic
- Improved naming

## Remaining limitations

- No database
- No authentication
- Console UI only

## Conclusion

The project successfully integrates key OOP and software engineering topics studied during the course.
