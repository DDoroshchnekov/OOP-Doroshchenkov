# Лабораторна робота №4  
## Тема: Абстрактні класи, інтерфейси та наслідування в C#

###  Мета роботи
Ознайомитися з принципами об’єктно-орієнтованого програмування: абстракцією, наслідуванням та поліморфізмом.  
Навчитися створювати інтерфейси та абстрактні класи, а також реалізовувати їх у похідних класах.

###  Завдання
1. Створити інтерфейс **`IArea`** з методом `CalculateArea()`.
2. Створити абстрактний клас **`Shape`**, який реалізує інтерфейс `IArea`.
3. На основі `Shape` створити класи **`Circle`** та **`Rectangle`**.
4. Реалізувати клас **`ShapeCalculator`**, який містить список об’єктів типу `Shape` і виводить інформацію про площі всіх фігур.
5. У головній програмі `Program.cs` дати можливість користувачу ввести параметри фігур і відобразити результати.
